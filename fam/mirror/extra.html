Beta software: use it at your own risk

{{NAME}} is a beta, made by one person for the M-VAVE FM-1 and not by M-VAVE. It can have bugs and fail: it can behave wrongly, lose what you saved, or leave the FM-1 not starting until you install a firmware again. This page writes to the FM-1 (the installer, the project and backup restore), so the same applies to it.

  • Save everything to a file before you install or restore, and keep that file.
  • Do not unplug the USB cable or switch the FM-1 off while it writes. If an update is cut, run it again.
  • To leave {{NAME}}, install another firmware with The Firmware Hub or M-UPGRADE.

Projects and backup

Save a project from the FM-1 to a file on this computer, or put a project file back into any of its four slots. You can also save everything {{NAME}} keeps (the sound, the patterns, the presets and the projects) and load it back later. This needs {{NAME}} 0.20 or later on the FM-1, connected above. The screen stops for a few seconds while the FM-1 sends or takes the data.

Connect to the FM-1 above first.

Projects

    A project file holds a project's sound and its patterns A to C. It can go into any slot, and into any FM-1 running {{NAME}}. To put one in, the sequencer must be stopped. The FM-1 then asks you to press SEL to confirm, or HOME to cancel.

    Everything

    A backup does not hold the button calibration, which belongs to the FM-1, or the Bluetooth pairing. Loading a backup replaces everything {{NAME}} has saved, and the FM-1 asks you to confirm with SEL first. A cut cable or a damaged file changes nothing.

    Install a version

    Put a {{NAME}} release from GitHub on the FM-1 over USB, or a package file (.fwsc) you downloaded. It takes about a minute, and the sound and the screen stop while it writes. The update only rewrites the firmware: what {{NAME}} has saved is not touched, but save everything first (above) if it matters.

    Connect to the FM-1 above first.

      The version the FM-1 runs shows on its HOME help pages. An older version installs too, but it may not read patterns saved by a newer one. M-UPGRADE refuses a package whose identity is the one already on the FM-1, and every {{NAME}} has the same one: this page does not compare them, so it can update {{NAME}} where M-UPGRADE cannot.
