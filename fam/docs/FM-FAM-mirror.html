Projects and backup

Save a project from the FM-1 to a file on this computer, or put a project file back into any of its four slots. You can also save everything FM-FAM keeps (the sound, the patterns, the presets and the projects) and load it back later. This needs FM-FAM 0.20 or later on the FM-1, connected above. The screen stops for a few seconds while the FM-1 sends or takes the data.

Connect to the FM-1 above first.

Projects

    A project file holds a project's sound and its patterns A to C. It can go into any slot, and into any FM-1 running FM-FAM. To put one in, the sequencer must be stopped. The FM-1 then asks you to press SEL to confirm, or HOME to cancel.

    Everything

    A backup does not hold the button calibration, which belongs to the FM-1, or the Bluetooth pairing. Loading a backup replaces everything FM-FAM has saved, and the FM-1 asks you to confirm with SEL first. A cut cable or a damaged file changes nothing.

    Install a version

    Put a FM-FAM release from GitHub on the FM-1 over USB, or a package file (.fwsc) you downloaded. It takes about a minute, and the sound and the screen stop while it writes. The update only rewrites the firmware: what FM-FAM has saved is not touched, but save everything first (above) if it matters.

    Connect to the FM-1 above first.

      The version the FM-1 runs shows on its HOME help pages. An older version installs too, but it may not read patterns saved by a newer one. M-UPGRADE refuses a package whose identity is the one already on the FM-1, and every FM-FAM has the same one: this page does not compare them, so it can update FM-FAM where M-UPGRADE cannot.

      How

      1. Plug the FM-1 running FM-FAM into this computer.
      2. Open this page in Chrome or Edge. Press Connect and allow MIDI with SysEx.
      3. The page finds FM-FAM by itself. If it doesn't, choose its ports (named after FM-FAM or the FM-1) in both lists above.

      What you see

      The screen updates as FM-FAM draws it. Buttons and keys light up as their LEDs do, bright or glowing. Held ones are outlined in teal. A knob you turn flashes and shows its steps. If you unplug the FM-1 or it sleeps, the page waits and reconnects.

      Control (for testing)

      Turn on Control to play the FM-1 from this page. Click a button or key, and it stays pressed while you hold the mouse. Scroll over a knob to turn it. With the keyboard, Tab to a button or key on the panel and hold Space or Enter to hold it; on a knob, the arrow keys turn it. When you turn Control off, close the page or unplug the cable, FM-FAM lets go of everything. Scripts can play the panel too, with fm1-base's tools/fm1_remote.py.

      Screen reader

      This page shows the screen as a picture. To hear what it says, open the FM-1 Screen Reader in another tab: it reads FM-FAM's screen with your own screen reader or its own voice, and it can run beside this page.

      Speed

      FM-FAM sends the screen after the notes and the clock, so the music always comes first. When the computer is busy, the page skips frames, but the picture always catches up.
